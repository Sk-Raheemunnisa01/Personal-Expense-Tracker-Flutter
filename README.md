# Abstract

The Personal Expense Tracker is a Flutter-based mobile application designed to simplify personal financial management. It enables users to record, organize, and monitor their daily income and expenses efficiently. Users can add transactions with details such as amount, category, date, and description, as well as edit or delete records when required. A dashboard provides a clear overview of total income, total expenses, and available balance, helping users understand their financial status easily.

The application also provides expense categorization, search and filtering options, and graphical representations of spending patterns. These features help users identify unnecessary expenses, plan budgets, and develop responsible spending habits. Developed using Flutter and Dart, the application offers a simple, responsive, and user-friendly interface. The main objective of this project is to provide a convenient digital solution for maintaining financial records and improving personal money management.
